# Deploy on Coolify (Docker Compose)

Target: Coolify 4.x on a shared 8 GB / 2 vCPU host, Traefik as the proxy. The bare-metal path in `docs/DEPLOY.md` is unchanged.

## Setup
1. New resource, Docker Compose, from GitHub `devrunch/ai-trader-2`, compose file `docker-compose.coolify.yml`.
2. Set the env vars below in Coolify, then assign the domain to the `web` service (port 80). Coolify fills `SERVICE_URL_WEB` from it, which feeds `APP_URL` and `CORS_ORIGINS`.
3. Deploy. `api` runs `node dist/migrate.js` before it starts; `market-data` and `web` wait for `api` to be healthy.

Only `web` is public. `/api/*` (REST and `/api/socket.io`) and `/health` are proxied by nginx to `api:8000`.

## Environment variables
Required (deploy fails without them):

| Var | Notes |
|---|---|
| `SESSION_SECRET` | 32+ chars |
| `ZERODHA_API_KEY`, `ZERODHA_API_SECRET`, `ZERODHA_USER_ID`, `ZERODHA_PASSWORD`, `ZERODHA_TOTP_SECRET` | required by the production config check |

Generated by Coolify: `SERVICE_PASSWORD_POSTGRES`, `SERVICE_URL_WEB`, `SERVICE_FQDN_WEB_80`.

Optional (blank = off): `KITE_AUTO_LOGIN` (default false), `RESEND_API_KEY`, `RESEND_DOMAIN`, `ALERT_EMAIL_TO`, `AGENT_MODEL`, `AGENT_FALLBACK_MODEL`, `AGENT_BASE_URL`, `AGENT_API_KEY`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `XAI_API_KEY`, `GOOGLE_GENERATIVE_AI_API_KEY`, `BEDROCK_API_KEY`, `BEDROCK_BASE_URL`, `AWS_REGION`, `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_SESSION_TOKEN`, `NEWS_API_KEY`, `LOG_LEVEL` (info).

`TRUST_PROXY` (default `1` in the compose file; `loopback` when unset elsewhere) is Express's `trust proxy`: one hop, nginx, which hands the API the real client address so per-IP limits work.

## Create the admin
It needs a TTY:

    docker exec -it $(docker ps -qf name=api- | head -1) node dist/cli/create-admin.js admin

(or the Coolify terminal on the `api` service).

## Memory budget (`mem_limit`)
api 768 MB (heap 448), market-data 320 MB (heap 192), web 64 MB, postgres 512 MB (`shared_buffers` 128 MB), redis 192 MB (`maxmemory` 128 MB, no eviction). Total 1856 MB. Do not raise postgres `max_connections` without lowering `DATABASE_POOL_MAX`.

## Notes
- Postgres 18 stores data under `/var/lib/postgresql`; the `pgdata` volume covers it. Redis persists with AOF in `redisdata`.
- The `api` and `market-data` services build the same image target; Docker's layer cache makes the second build a no-op.
