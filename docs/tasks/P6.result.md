## Deviations from the brief, and why
- **No built-in indicators in Python.** The brief allowed "series supplied by the caller or computed from a small set of built-ins". SRD FR-IN-1 (one engine) and §10.2 ("They no longer compute indicators themselves") rule out a Python indicator set; a second implementation is how VWAP and Bollinger drifted before. Callers send engine series; the bars' own fields are always available.
- **Response validation uses generated Zod schemas, not openapi-typescript.** R-10 forbids casting unknown JSON to a type; hey-api generates both the types and Zod schemas from the same document, so the client validates without hand-written schemas.
- **`httpx2` instead of `httpx`** for the FastAPI test client: Starlette 1.10 deprecates `httpx` for its test client.
- **No Nest module or config yet.** `HttpComputeGateway` and `RunBacktest` are not registered in the app (no `COMPUTE_URL` in `AppConfig`, no controller), so that `shared/config` and `app.module` stay untouched until the controller task. They are reachable from their specs only.
- **The port imports types from `@aitrader/compute-client`.** The generated types are the cross-language contract, like `@aitrader/contracts`; depcruise allows it. Say if you want the application layer to own its own request and response types instead.
