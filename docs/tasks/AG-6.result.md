# AG-6 assistant run queue (BullMQ on Redis)

- The minute tick (`AgentTaskJob`) now only evaluates and enqueues: a task that runs the assistant or the desk is saved as `queued` with its `pendingFire` (key + reason) and then enqueued under job id `taskId-fireKey` (so the same fire twice is one job); plain alerts are still sent inline. One run in flight per task. If Redis is down the task is put back as it was and fires on the next tick; a queued run nobody picked up for 10 minutes is queued again (lost-job recovery). Migration `0032_agent_run_queue` (`run_state`, `run_state_at`, `pending_fire`).
- Workers (`AgentRunQueue`, `RunProcessor`, `TaskFirer`): `AGENT_RUN_CONCURRENCY` (default 2); timeout 120 s per agent run and 240 s per desk run; 3 attempts (2 retries) with exponential backoff for transient failures (model/network/timeouts, via `TransientRunError`), none for validation/conflict/not-found/rate-limit refusals; the last attempt records the error instead of dropping the run. State goes queued -> running -> idle with `lastOutcome`; a job whose worker died is retried by BullMQ's stalled-job check and the processor finishes a run left in `running`.
- Caps are enforced when the run starts (`AGENT_WATCH_DAILY_RUNS` in `TaskFirer`, the desk cap in `TradingDesk`; a capped run is recorded as `capped` and does not use up the task's runs). Shutdown: the worker drains for up to 30 s, then is forced closed (the queue re-delivers the job elsewhere), then the queue closes. The completed-job window (1 h) keeps dedupe working; failed jobs are kept 24 h.
- Admin: `GET /v1/admin/ops/agent-queue` and an "Assistant run queue" card on the Jobs tab (waiting, running of N, failed last 24 h; "failed" counts jobs that exhausted their retries).
- Tests: `agent-tasks.spec` (queued state, no refire while pending, key per fire, queue-down rollback, 10-minute recovery), `run-processor.spec` (states, retry vs no retry, last attempt, cap, stale/duplicate job, died-while-running, cancelled, timeouts), `task-firer.spec`, `agent-run-queue.spec` (dedupe id, options, shutdown drain and force), admin card spec. Gate passes. NOT RUN: `test/agent-run-queue.int-spec.ts` (real Redis: dedupe, retries, concurrency, drain) and migration 0032, since there is no Docker here; please run `pnpm test:int`.
