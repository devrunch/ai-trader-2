## Deriv rules
- **Endpoint:** `wss://ws.derivws.com/websockets/v3?app_id=<DERIV_APP_ID>`. Add `DERIV_APP_ID` to `AppConfig` (optional, default `1089`, Deriv's public testing app ID).
- **Messages are JSON:**
  - subscribe: `{"ticks":"frxEURUSD","subscribe":1,"req_id":n}`. The reply is `{"tick":{"symbol","epoch","quote"},"subscription":{"id"}}`; keep a `symbol → subscription.id` map;
  - unsubscribe: `{"forget":"<id>"}`;
  - keepalive: `{"ping":1}` every 30 s;
  - an `error` field gives an error `{code, message}`. `InvalidAppID` → close with reason `PROVIDER_DOWN`; a market-closed code → no tick, no error.
- **Ticks:** `Tick.at` = `epoch * 1000`, `price` = `quote`, `cumVolume` = `null` (Deriv has no volume).
- **History:** `{"ticks_history":"frxEURUSD","style":"candles","granularity":60|86400,"start":<sec>,"end":<sec>,"count":5000}`.
  - Chunk by 5,000 candles; candles `{epoch, open, high, low, close}`; volume `null`.
  - Each request has a 15 s timeout, behind a breaker (3 failures → 60 s open).
  - An empty result → `NO_DATA`; `MarketIsClosed` → `MARKET_CLOSED`.
- **History requests go over the socket,** sharing one connection with `req_id` correlation, or a short-lived separate connection; your choice. Never block live ticks behind history.
- **The feed:** `DerivFeed extends ResilientFeed` (or composes it), with a Deriv `FeedTransport`. The watchdog, backoff and gap backfill come from `ResilientFeed`, unchanged.

## US delayed rules
- **Library:** `yahoo-finance2` (exact latest 4.x). Symbol mapping: `BRK.B` → `BRK-B`; others as they are.
- **History:** `chart(symbol, { interval: '1m' | '1d', period1, period2 })`.
  - 1-minute requests are chunked to ≤ 7 days and only go back 30 days. Older 1-minute requests → `NO_DATA`, with detail `yahoo keeps 30 days of 1m`.
  - Timestamps are bar starts (UTC).
- **Errors:** HTTP 429 → `RATE_LIMITED` (`retryAfterMs` 60,000); network or 5xx → `PROVIDER_DOWN`; an unknown symbol → `UNSUPPORTED`. A breaker wraps the calls (3 failures → 5 min open). Each request has a 15 s timeout.
- **The feed:** `UsDelayedFeed` implements `LiveFeed` (polling, not a socket).
  - Every 60 s, for subscribed symbols whose NYSE/NASDAQ session is open, fetch the latest 1-minute bars. Emit one `Tick` per new bar close, with `at` = bar close.
  - `delayMs = 15 * 60_000`.
  - Batch at most 10 symbols per cycle, staggered to stay polite.
  - State is `live` while polls succeed, `stale` with the reason after 3 consecutive failures, and back to `live` on success.
  - Its ticks are delayed by design: never present them as live.
