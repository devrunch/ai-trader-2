## Interfaces
- **Produces:** `generateClassDiagram(tsconfigPath: string, moduleDir: string): string`. It returns Mermaid `classDiagram` text covering every exported class and interface declared under `moduleDir`:
  - public methods and properties, with their types as written;
  - `Interface <|.. Class` for `implements`;
  - `Base <|-- Derived` for `extends`;
  - `Class --> Dependency` for each constructor parameter whose type is a class or interface declared under `moduleDir`.

  Output is sorted (nodes by name, members by name, edges lexicographically), so it's deterministic. No timestamps.
- **Root scripts:**
  - `diagrams`: `node scripts/diagrams/run.ts`. Node 26 runs TypeScript directly; if it can't, use `tsx` (exact version). It writes:
    - `architecture/features/<name>/classes.mmd` for each `apps/api/src/modules/<name>` and each `apps/web/src/features/<name>`. None exist yet, so nothing is written; the code path must still exist and be tested by the fixture;
    - `architecture/generated/deps.mmd`: `depcruise apps packages --config .dependency-cruiser.cjs --output-type mermaid --collapse "^(apps/[^/]+/src/(modules|features|shared)/[^/]+|packages/[^/]+)"`;
    - `architecture/generated/knip.md`: knip's markdown reporter output (`knip --reporter markdown`), written even when clean;
    - `architecture/generated/jscpd.md`: configure jscpd's markdown output to land here (rename `jscpd-report.md`).
  - `diagrams:check`: `node scripts/diagrams/check.ts`.
    1. Hash every generated path (`architecture/generated/**`, `architecture/features/**/classes.mmd`).
    2. Run `diagrams`, then hash again.
    3. Exit 1 listing changed or new or removed files if anything differs, otherwise 0.

    (Untracked files make `git diff` blind, so don't use git here.)
  - `diagrams:serve`: `likec4 serve architecture/model`
  - `diagrams:build`: `likec4 build architecture/model -o architecture/site`
  - `diagrams:validate`: `likec4 validate architecture/model`; also added to `check` before `diagrams:check`.

## LikeC4 model (LikeC4 1.x, latest)
- **`spec.c4`:** element kinds `actor`, `system`, `container`, `component`, `store`, `external`, each with a distinct shape and colour; relationship kinds `calls`, `streams`, `reads`, `writes`.
- **`system.c4`:**
  - **Actors:** `trader`, `admin`.
  - **System `aitrader`, with containers:**
    - `web` (React SPA, SRD §10.3);
    - `api` (NestJS, §10.1);
    - `marketData` (Node, vendor sockets and the bar builder, §7.2);
    - `compute` (Python FastAPI, stateless, §10.2).
  - **Stores:** `postgres` (§10.4), `redis` (§10.4).
  - **Externals:** `kite`, `deriv`, `bedrock`, `agentcore`, `telegram`.
  - **Relationships:**
    - trader → web;
    - web → api (calls REST, streams socket);
    - api → postgres and redis;
    - marketData → kite and deriv (streams), marketData → redis (writes ticks);
    - api → compute (calls);
    - api → bedrock and agentcore (calls);
    - api → telegram (calls).
  - **Views:** `index` (system context), `containers` (inside `aitrader`).

## Tests to write first (`scripts/diagrams/gen-class-diagrams.spec.ts`)
Fixture: `port.ts` has `export interface Port { get(id: string): Promise<number>; }`, `impl.ts` has `export class Impl implements Port { … }`, and `service.ts` has `export class Service { constructor(private readonly port: Port) {} run(): void {} }` plus `export class Base {}` and `export class Derived extends Base {}`.
- `emits implements edges` → output contains `Port <|.. Impl`
- `emits extends edges` → contains `Base <|-- Derived`
- `emits injected dependencies` → contains `Service --> Port`
- `lists public methods` → contains `+run() void` inside the `Service` block
- `is deterministic` → two calls return identical strings
- `ignores declarations outside moduleDir` → no node named `Promise` or `string`
