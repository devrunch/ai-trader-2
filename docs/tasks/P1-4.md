- **Kite:** NSE, BSE, MCX, NFO and indices;

## Interfaces (exact)
```ts
// application/ports/instrument-source.ts
export interface ProviderMapping { id: string; provider: 'kite' | 'deriv' | 'us-delayed'; providerSymbol: string; providerToken?: string }
export interface SourceSnapshot { instruments: Instrument[]; mappings: ProviderMapping[] }
export interface InstrumentSource { readonly name: 'kite' | 'deriv' | 'nasdaq'; fetch(signal: AbortSignal): Promise<SourceSnapshot> }
export const INSTRUMENT_SOURCES: symbol; // DI token for InstrumentSource[]
```
Each source takes an injectable `fetchText(url, signal): Promise<string>` (default: global `fetch` with a 30 s `withTimeout` from `@aitrader/resilience`), so tests feed fixtures. `today` comes from an injected clock (`() => Date`), formatted as `YYYY-MM-DD` in `Asia/Kolkata`.

## Kite mapping rules (`kite-mapping.ts`, pure functions; every rule has a test)
- **Cash equities** (`segment` NSE or BSE, `instrument_type` EQ):
  - ID `<EXCHANGE>:<tradingsymbol>`; description from `name`; type `etf` when `name` matches `/\bETF\b|BEES$/i`, else `stock`;
  - currency INR, timezone `Asia/Kolkata`, session `0915-1530`;
  - `minmov = 1`, `pricescale = round(1 / tick_size)` (0.05 → 20, 0.01 → 100); `lotSize = lot_size || 1`;
  - `hasIntraday: true`, `volumeType: 'real'`, `status: 'active'`, aliases `[]`;
  - series-suffixed symbols (`OMFURN-SM`) are kept as their own tickers.
- **Indices** (`segment === 'INDICES'`): type `index`, `pricescale` 100, `minmov` 1, `lotSize` 1, `volumeType: 'none'`.
  - **TradingView alias table** (canonical ticker ← Kite name): `NIFTY` ← `NIFTY 50`, `BANKNIFTY` ← `NIFTY BANK`, `CNXFINANCE` ← `NIFTY FIN SERVICE`, `CNXIT` ← `NIFTY IT`, `INDIAVIX` ← `INDIA VIX`, `SENSEX` ← `SENSEX` (BSE).
  - Other indices: the ticker is the Kite name with spaces removed and `&` kept.
  - The Kite name is always added to `aliases` when it differs from the ticker.
- **Dated futures** (MCX or NFO `instrument_type === 'FUT'`):
  - the root is `name` (e.g. `GOLD`, `NIFTY`, `RELIANCE`); the ID exchange is `MCX` for MCX and `NSE` for NFO;
  - ticker `<ROOT><MONTHCODE><YYYY>`, with month codes `F G H J K M N Q U V X Z` (TradingView convention). E.g. `NSE:NIFTYX2026` (Nov 2026), `MCX:GOLDZ2026`;
  - type `futures` for NFO, `commodity` for MCX (it remains a future: `expiry` set);
  - `underlying` = `NSE:<ROOT mapped through the index alias table when it's an index>` for NFO (`NIFTY` → `NSE:NIFTY`), or `MCX:<ROOT>` for MCX;
  - the Kite `tradingsymbol` goes into `aliases`.
- **Options** (NFO or MCX `instrument_type` CE or PE):
  - ticker `<ROOT><YYMMDD><C|P><STRIKE>`, where the strike is written without trailing zeros (24000, 24050.5). E.g. `NSE:NIFTY261124C24000`;
  - type `option`, plus `strike`, `optionType`, `expiry` and `underlying` as for futures;
  - the Kite `tradingsymbol` goes into `aliases`.
- **Continuous futures:** for every root with dated futures, add synthetic instruments `<EXCH>:<ROOT>1!` and `<EXCH>:<ROOT>2!`:
  - type `futures` (NFO) or `commodity` (MCX), no expiry;
  - description `<ROOT> continuous (front month)` and `(next month)`;
  - mapping provider `kite` with `providerSymbol = 'continuous:<EXCH>:<ROOT>:<rank>'`. Resolution happens at runtime through `resolveContinuous`; don't resolve here.
- **Mappings** for every real row: `{ id, provider: 'kite', providerSymbol: '<kite exchange>:<tradingsymbol>', providerToken: exchange_token }`. The `instrument_token` is kept internal (Phase 2 needs it for the websocket): add it as a second mapping with `provider: 'kite'`? No: one mapping per `(id, provider)`. Encode it as `providerToken = '<exchange_token>/<instrument_token>'`, and document the format in `kite-mapping.ts`.
- **Skipped rows:** `instrument_type` other than EQ, FUT, CE, PE; segments other than NSE, BSE, INDICES, NFO-FUT, NFO-OPT, MCX-FUT, MCX-OPT; rows whose ID fails `InstrumentId.parse`. They are counted and logged once, as a number, never per row.

## Deriv (`deriv-pairs.ts`, a fixed table carried over from the old project)
`AUDCAD AUDCHF AUDJPY AUDNZD AUDUSD EURAUD EURCAD EURCHF EURGBP EURJPY EURNZD EURUSD GBPAUD GBPCAD GBPCHF GBPJPY GBPNZD GBPUSD NZDJPY NZDUSD USDCAD USDCHF USDJPY USDMXN USDPLN` → `FX:<PAIR>`, type `forex`. `XAUUSD XAGUSD XPTUSD XPDUSD` → `OANDA:<PAIR>`, type `metal`.
- **Descriptions:** like `EUR/USD`, `Gold/USD`.
- **Fields:** currency = the quote currency (the last 3 letters); timezone `UTC`; session `24x5`; `pricescale` 100000 for forex, 1000 for JPY quotes, 100 for metals; `minmov` 1; `lotSize` 1; `volumeType: 'tick'`; `hasIntraday: true`.
- **Mappings:** `{ provider: 'deriv', providerSymbol: 'frx<PAIR>' }`.
- `fetch` returns this table and never touches the network.

## Nasdaq Trader
- **Sources:** `https://www.nasdaqtrader.com/dynamic/SymDir/nasdaqlisted.txt` and `otherlisted.txt`.
- **Exchange mapping:**
  - nasdaqlisted rows → `NASDAQ`;
  - otherlisted `Exchange` codes: `N` → `NYSE`, `A` → `AMEX`, `P` → `NYSEARCA`, `Z` → `CBOE`, `V` → `IEX`; others are skipped and counted.
- **Skipped rows:** `Test Issue === 'Y'`, the header and the footer line.
- **Tickers:** the symbol as given (`BRK.B` stays `BRK.B`).
- **Type:** `etf` when the ETF column is `Y`, else `stock`.
- **Fields:** USD; `America/New_York`; session `0930-1600`; `pricescale` 100; `minmov` 1; `lotSize` 1; `volumeType: 'real'`; `hasIntraday: true`.
- **Mappings:** `{ provider: 'us-delayed', providerSymbol: <symbol> }`.
