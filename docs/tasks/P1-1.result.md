## Tests

The 14 test names (12 original tests and two manager-review regressions):

1. parses and formats canonical ids
2. rejects malformed ids
3. tryParse returns null instead of throwing
4. equals compares exchange and ticker
5. diff detects listed, delisted, expired, renamed by ISIN, updated
6. a rename does not also report listed or delisted
7. diff is deterministic
8. custom identity function detects renames by vendor token
9. compares fields deeply while ignoring id object identity
10. parses continuous ids
11. continuous contract rolls to the next expiry after the last trading day
12. continuous returns null when no contract is unexpired
13. same ISIN on another exchange is not a rename
14. an existing instrument is never a rename successor
