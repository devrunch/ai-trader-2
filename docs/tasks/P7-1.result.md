# P7-1 Result (first slice): agent foundations and the prompt registry

Implemented by the manager (Codex out of quota until 2026-12-09; no subagents per the owner).

## What changed
- **Pins** (each at least 14 days old): `@mastra/core` 1.79.0, `@mastra/ai-sdk` 1.11.2, `ai` 7.0.155, `@ai-sdk/amazon-bedrock` 4.0.204, `@ai-sdk/react` 4.0.159.
- **`TurnBudget`:** rounds, wall clock and tokens per turn. Once exceeded it stays exceeded (FR-AG-3).
- **`guardedTool`:**
  - schema-validated input;
  - a per-user and per-conversation rate limit;
  - an audit entry per call;
  - typed reasons, never thrown (FR-AG-5).
- **`buildReadTools`:** `getQuote`, `getBars` (at most 500), `searchInstruments`, and `getPortfolio`, which always reads the caller's own account (the user id comes from the session).
- **No-orders guarantees (FR-AG-4), enforced in code:**
  - a test enumerates the tools;
  - a source scan fails if any agent file mentions order placement, cancellation or Kite credentials.
- **Prompt registry (owner request 2026-11-10):**
  - `prompts/system.md` is the reviewed default, with the standing rules: numbers from tools, server-side geometry, no performance figure without risk context, tool text is data.
  - Versions are append-only like commits (`commit`, `revert`, `lineDiff`). Migration `0011_prompt_registry` has primary key `(key, version)`, so a concurrent save is a 409, not an overwrite.
  - The admin API offers list, detail, diff, save, revert and reset. The author comes from the session; CSRF is required on writes.
  - The admin Prompts tab has an editor with a change message, history, a diff against the active version, revert, and reset to the file default.
