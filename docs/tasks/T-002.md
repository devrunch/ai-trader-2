# Task T-002: Workspace skeleton

Read `AGENTS.md` first. It's binding. Do only what this brief asks.

## Goal
A pnpm workspace with two apps and two packages that installs, builds and tests, on the latest stable versions.

## SRD
§10.1 (Node backend, NestJS), §10.3 (Vite + React SPA), NFR-QL-1 (TypeScript strict).

## Files
- Create, at the root:
  - `package.json`: `"private": true`, `"packageManager": "pnpm@12.18.0"`, `"engines": { "node": ">=22.13" }`, scripts `build`, `typecheck`, `test`, `lint` (placeholder `echo "lint: Task 3"` for now);
  - `pnpm-workspace.yaml`: `apps/*`, `packages/*`;
  - `tsconfig.base.json`;
  - `.prettierrc` (`{ "singleQuote": true, "trailingComma": "all", "printWidth": 100 }`);
  - `vitest.workspace.ts` (or the Vitest 5 `projects` equivalent in the root `vitest.config.ts`).
- Create `packages/contracts/{package.json,tsconfig.json,src/index.ts}`, named `@aitrader/contracts`. `src/index.ts` exports nothing yet except `export {};`.
- Create `packages/resilience/{package.json,tsconfig.json,src/index.ts}`, named `@aitrader/resilience`, the same way.
- Create `apps/api/{package.json,tsconfig.json,tsconfig.build.json,nest-cli.json,vitest.config.ts,src/main.ts,src/app.module.ts}`, named `@aitrader/api`.
- Create `apps/web/{package.json,tsconfig.json,vite.config.ts,index.html,src/main.tsx,src/app/app.tsx}`, named `@aitrader/web`.
- Test: `apps/api/src/app.module.spec.ts`, `apps/web/src/app/app.spec.tsx`.

## Versions
Exact versions, no `^` or `~`. Use the latest stable on npm when you install, except TypeScript, which stays `6.0.x`, the latest 6.0 patch: NestJS CLI 12 and typescript-eslint need `<6.1`.

Expected (checked 2026-11-08):
- **API:** `@nestjs/core`, `@nestjs/common`, `@nestjs/platform-express` 12.4.x; `@nestjs/cli` 12.0.x; `@nestjs/testing` 12.4.x; `reflect-metadata` and `rxjs` latest.
- **Web:** `vite` 8.3.x; `react` and `react-dom` 19.3.x; `@vitejs/plugin-react` 6.2.x with `babel-plugin-react-compiler` 1.0.x; `@testing-library/react` 16.3.x; `jsdom` latest.
- **Tests:** `vitest` 5.1.x, plus `unplugin-swc` 2.0.x and `@swc/core` latest so Vitest compiles Nest decorators with metadata.

## tsconfig.base.json
`strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `noImplicitOverride`, `noFallthroughCasesInSwitch`, `forceConsistentCasingInFileNames`, `skipLibCheck: true`, `target: ES2023`, `module` and `moduleResolution` appropriate per project. `experimentalDecorators` and `emitDecoratorMetadata` go in `apps/api/tsconfig.json` only.

## Interfaces
- **Produces:**
  - workspace packages `@aitrader/contracts`, `@aitrader/resilience`, `@aitrader/api`, `@aitrader/web`;
  - `apps/api/src/app.module.ts` exports `AppModule` (empty `@Module({})`);
  - `apps/web/src/app/app.tsx` exports `App`, which renders `<div data-testid="app-root">AI Trader</div>`;
  - `apps/web/src/main.tsx` mounts `App` into `#root`;
  - `apps/api/src/main.ts` bootstraps `AppModule` on port 8000 (env handling arrives in Task 5; hard-code 8000 here with a `// config arrives in T-005` comment).

## Tests to write first
- `apps/api/src/app.module.spec.ts` → `it('boots the Nest application', …)`: build a `TestingModule` with `AppModule`, `createNestApplication()`, `init()`, and expect `app.getHttpServer()` to be defined; close the app.
- `apps/web/src/app/app.spec.tsx` → `it('renders the root without crashing', …)`: render `<App />` and expect `screen.getByTestId('app-root')` to have the text `AI Trader`.

## Steps
1. Create the config files and test files first. Run `pnpm install` then `pnpm test` and confirm both tests FAIL (missing modules). Paste the failure tail into the result.
2. Implement the minimal app files.
3. Run `pnpm install`, `pnpm build`, `pnpm typecheck`, `pnpm test`. All must pass.
4. Write `docs/tasks/T-002.result.md` (AGENTS.md §0), including the exact installed versions of every dependency (`pnpm list -r --depth 0`).

## Done when
- `pnpm install && pnpm build && pnpm typecheck && pnpm test` exit 0 from a clean clone.
- `apps/api/dist/main.js` and `apps/web/dist/index.html` exist after build.
- No `^` or `~` in any `package.json`.
- `pnpm-lock.yaml` committed (it's created; the manager commits).

## Out of scope
ESLint, dependency rules, diagrams, config loading, routing, styling. Those are later tasks.
