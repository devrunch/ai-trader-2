## Ichimoku offsets
`Builtin.plotOffsets(inputs)` gives per-plot offsets that add to the `offset` input. Ichimoku returns `lagging: −(displacement − 1)` and `leadA`/`leadB: displacement − 1`, applied through `domain/offset.ts` (`shiftByOffset` for batch, `OffsetStream` per plot for live). The read pads the bar request by the largest positive offset.

## Judgment calls
- **`IndicatorStream.push` still returns one point.** Plots with different offsets paint different bars; the point holds the newest bar's plots. Plots painted onto older bars (Ichimoku's lagging span, a negative `offset`) are left to the next compute, because `live-indicators.ts` can only replace or append the last bar. The lagging span is empty on the newest bars anyway.
- **Parity uses PineTS, with one source written out.** PineTS's `ta.hma` truncates `sqrt(n)`; the Pine reference rounds it. The HMA source spells out the reference expression, so non-square lengths (14) are compared too. PineTS's `timeframe.change("D")` is false on the first bar, so the pivot source adds `or na(close[1])`, as the VWAP source does.
- **`dmi` and `adx` are separate entries.** TradingView ships both scripts (ADX alone has one plot). They share a kernel.
- **Ichimoku has no cloud fill.** The contract has no fill; the two spans are plain lines (green, red).
- **Pivots:** `Type` has the single option `Traditional` for now (other types are not in the brief). The plots are `step` lines in ids `r5…s5`, `p`. Days are cut by `anchorKey(…, 'Session', zone)`. On `1D`, every bar is its own "day", so the pivots come from the previous bar.
- **Colours** are the nearest theme token to TradingView's (ADX red, +DI blue, −DI orange; Ichimoku conversion blue, base red, spans green/red).
- **Donchian, HMA, DEMA, TEMA** have no `Offset` input; VWMA has one. Keltner has none. I could not check TradingView's current scripts for these.
- **OBV warm-up is 0.** It is a running total from the first bar read, so a chart with more history than the read window differs from TradingView by a constant.
- **Commit:** one commit for the batch (the kernels share helpers), not one per indicator.

## Open
- **Ties in Aroon:** the newest bar wins (`ta.highestbars` is documented to return the offset to the highest value, not the tie rule). The random fixtures never tie; unverified against TradingView.
- **Flat windows:** CCI, %R and Stochastic return `null` on zero deviation or range; MFI returns 100 when the negative flow is 0. None is hit by the fixtures. Check against TradingView reference captures (P4-7).
- **Parity is against PineTS,** which matched TradingView to about 1e-9 in the benchmark for the original ten; nothing here is compared with captured TradingView values yet.
- **Pivots over a short read:** the first day in the read has no previous day, so its pivots are `null`; warm-up covers two days.
