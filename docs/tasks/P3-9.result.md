# P3-9 Result: official previous close from Zerodha

Owner's point: Zerodha already gives the previous close, so don't rebuild it from bars.

## What changed
- **`Tick.prevClose`:** the Kite WebSocket client maps `ohlc.close` from quote and full packets. It's verified on a real captured NIFTY frame from 2026-11-09: previous close 24,986.40.
- **`LiveBars`:** saves it once per instrument and trading day (leader only) through `PreviousCloseStore`.
- **`RedisPreviousCloseStore`:** `md:prev-close:<id>` holds `{ close, forDate }`, with a 5-day TTL.
- **`KitePreviousCloseSource`:** `/quote/ohlc` for instruments not streaming, using the mapping's Kite symbol, with its own 1 request/s bucket (`rl:kite:quote`).
- **`GetQuote`, in order:** the official close saved for the quote's session; then the Kite quote, only when the quote's session is today (cached afterwards); then the previous close from bars.
- **Why it matters:** for F&O stocks the official close is the closing-auction price, which no minute bar holds.
