## Judgment calls

- **Plot type is limited to the plot's own series family** (line/step/circles; histogram/columns; area alone), because `applyOptions` cannot change a series class and the brief forbids recreating. Histogram and columns look the same (Lightweight Charts has one histogram series).
- **Precision is per indicator**, as on TradingView, not per plot.
- **Hidden on an interval** hides the series and level lines but still computes and subscribes, so switching back is instant.
- **No seconds intervals exist**, so the seconds group is shown but never matches. Hours counts: 60 is 1h, 240 is 4h.
- **Pane choice** is offered only for a chained child, and applied only when it has a parent.
- **Custom colour** is a fixed `#rrggbb`; theme tokens stay theme-aware.
- **Persistence:** the store is in memory (as before); presets and templates (FR-IN-12/14) will persist it.
