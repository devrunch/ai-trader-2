# Task P2-8: MarketDataService and REST

## Goal
One facade and two endpoints. They serve bars and quotes for any canonical instrument (continuous futures included), with honest status:
- `ok` when the data is current;
- `delayed` with the delay;
- `stale` with the reason;
- a typed error when there's nothing to show.

Nothing silently swaps one vendor for another.

## Contracts (`@aitrader/contracts`, strict objects)
```ts
export const INTERVALS = ['1','3','5','15','30','60','240','1D','1W','1M'] as const;
export const DataStatusSchema = z.discriminatedUnion('state', [
  z.object({ state: z.literal('ok') }),
  z.object({ state: z.literal('delayed'), delayMs: z.number().int().positive() }),
  z.object({ state: z.literal('stale'), reason: z.enum(PROVIDER_REASONS), detail: z.string().optional() }),
]);
export const BarSchema = z.object({ time: z.number().int(), open: z.number(), high: z.number(), low: z.number(), close: z.number(), volume: z.number().nullable(), repaired: z.boolean().optional() });
export const BarsResponseSchema = z.object({ instrumentId: z.string(), resolvedId: z.string(), interval: z.enum(INTERVALS), bars: z.array(BarSchema), nextBefore: z.number().int().nullable(), status: DataStatusSchema });
export const QuoteResponseSchema = z.object({ instrumentId: z.string(), resolvedId: z.string(), price: z.number(), change: z.number().nullable(), changePct: z.number().nullable(), at: z.number().int(), status: DataStatusSchema });
```
`PROVIDER_REASONS` moves to contracts (`NO_DATA`, `MARKET_CLOSED`, `UNSUPPORTED`, `RATE_LIMITED`, `PROVIDER_DOWN`, `AUTH_EXPIRED`); the API's `ProviderReason` type imports it from there.

## Endpoints
- **`GET /api/v1/bars?symbol=<id>&interval=<i>&before=<ms>|since=<ms>&limit=<n>`:**
  - `symbol` is URL-encoded; `limit` is 1–5,000, default 500; at most one of `before` and `since`; neither means latest.
  - Invalid input → 422.
  - Response: `BarsResponseSchema`.
- **`GET /api/v1/quote/:id`** → `QuoteResponseSchema`. The price is the forming bar's close if one exists, otherwise the last stored 1-minute close. `change` is against the previous session's last close.

Both endpoints use the existing per-IP rate-limit guard (capacity 60, 20/s).

## Service rules (`MarketDataService.bars(id, interval, cursor, limit)`)
1. **Resolve** `id` with `ResolveInstrument`. Continuous IDs read the **resolved dated contract's** bars (`resolvedId` in the response), and history before that contract's listing isn't spliced (out of scope; documented). Unknown → 404 `SYMBOL_NOT_FOUND` (the existing error).
2. **Status:**
   - the vendor feed state is `stale`, or the read reports `stale` → `{ state:'stale', reason }`;
   - the provider is `us-delayed` → `{ state:'delayed', delayMs: 900000 }`;
   - otherwise `ok`.
3. **Errors:**
   - no bars at all and the read failed → an HTTP error by reason: `AUTH_EXPIRED` → 503 `PROVIDER_DOWN` with `details.reason: 'AUTH_EXPIRED'`; `PROVIDER_DOWN` → 503; `RATE_LIMITED` → 429 with `Retry-After`; `UNSUPPORTED` → 422 `VALIDATION_FAILED`;
   - `NO_DATA` or `MARKET_CLOSED` → **200** with `bars: []` and `status: { state:'stale', reason }`, so the UI can say "market closed".
4. **No fallback (E3):** never route an instrument to a different provider when its own provider fails.
