# Task P1-8a: C4 model generated from code

Read `AGENTS.md` first. It's binding. Do only what this brief asks.

## Goal
The LikeC4 model always matches the real code. A generator writes `architecture/model/generated.c4` from the source tree and the real imports. `pnpm diagrams:check` fails when that file is stale. The hand-written `system.c4` keeps the intent: actors, external systems, descriptions, SRD references.

## SRD
§14 (diagram duties), AGENTS.md §7. Owner request: "C4 diagrams generated for code".

## Files
- Create: `scripts/diagrams/gen-c4.ts`, `scripts/diagrams/gen-c4.spec.ts`, `scripts/diagrams/fixtures/c4/…` (a tiny fake `apps/api/src` and `apps/web/src` tree).
- Modify: `scripts/diagrams/run.ts` (also write `architecture/model/generated.c4`), `scripts/diagrams/check.ts` (include it in the staleness hash), `architecture/model/system.c4` (see "Split" below), `architecture/README.md` (3 lines on which file is generated).

## What to generate (`generateC4(repoRoot): string`)
Deterministic output (sorted, no timestamps), valid LikeC4 1.x, using only element and relationship kinds from `spec.c4` (`component`, plus `calls` for import edges). Inside `extend` blocks for the containers that `system.c4` defines:

1. **API** (`extend aitrader.api { … }`):
   - one `component` per `apps/api/src/modules/<m>` with ID `mod_<m>`, title `<m>`, technology `NestJS module`;
   - one per `apps/api/src/shared/<s>` with ID `shared_<s>`, and nested `shared/vendors/<v>` as `shared_vendors_<v>`;
   - inside each module component, one nested `component` per existing layer folder (`api`, `application`, `domain`, `infrastructure`), with IDs `api`, `app`, `domain`, `infra`.
2. **Web** (`extend aitrader.web { … }`): one `component` per `apps/web/src/features/<f>` (`feat_<f>`) and per `apps/web/src/shared/<s>` (`shared_<s>`), plus `app` for `apps/web/src/app`.
3. **Packages:** top-level `component` elements `pkg_<name>` for `packages/<name>`.
4. **Relationships:** from dependency-cruiser's JSON output (reuse the repo config and run it programmatically). Collapse to the elements above, drop self-edges, de-duplicate, and emit `<from> -[calls]-> <to> 'imports'`:
   - layer to layer inside a module;
   - module to module (cross-module);
   - module or shared to package;
   - web feature to shared.
5. **Views** (`views { … }` in the generated file):
   - `api_code` (API components generated from code, including the packages);
   - `web_code`;
   - one view per API module, `module_<m>`, showing its layers and their edges.

Description lines say `generated from code — do not edit`.

## Split with the hand-written model
`system.c4` keeps the containers, actors, externals, stores, the containers view and descriptions. Remove from `system.c4` the hand-written API and web *components* added at the Phase 0 close (config, errors, observability, health, database, redisClient, shell, apiClient, liveStore, theme) and their component-level relationships. They're now generated with real edges. Keep the container-level relationships. `likec4 validate architecture/model` must pass with both files.

## Tests to write first (`gen-c4.spec.ts`, on the fixture tree)
- `emits one component per module with its layers`;
- `emits shared, vendor and package components`;
- `emits import edges collapsed to components without self-edges or duplicates`;
- `is deterministic` (two runs give identical text);
- `output validates with likec4` (write the fixture output plus a minimal `spec.c4` into a temp directory and run LikeC4's validate programmatically or through its CLI; expect success).

## Steps
1. Write the tests and confirm they FAIL; paste the tail.
2. Implement. Then run `pnpm diagrams` on the real repo, `pnpm diagrams:validate` and `pnpm check` (exit 0).
3. Run `pnpm diagrams:serve` for at most 20 s and report the view IDs it lists; stop it.
4. Write `docs/tasks/P1-8a.result.md`, including the number of components and edges generated for the real repo.

## Done when
- 5 tests pass; `pnpm check` exits 0; `generated.c4` is committed and current.
- Editing an import in a module and rerunning `pnpm diagrams:check` exits 1, naming `generated.c4` (demonstrate it, then revert).

## Out of scope
Changing the containers, externals or descriptions in `system.c4` (beyond removing the generated components).
