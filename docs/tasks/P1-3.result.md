- Updated three existing app/health/infrastructure test files because KiteModule adds a database provider dependency and readiness check. Tests keep their existing isolation; production rules are unchanged.
- Added smoke-script tsconfig for typed ESLint analysis, plus two HTTP adapter tests for the specified transport behavior.
- The exact SDK exchange interface has no AbortSignal parameter. The adapter receives a signal through its factory and bounds awaiting with withTimeout; KiteConnect also has a 15-second transport timeout. Caller abort stops awaiting immediately, but underlying SDK transport may continue until its own timeout.
- No commits, merges, pushes or manager-owned files changed. The smoke script was NOT run.
