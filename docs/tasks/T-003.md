# Task T-003: Quality gates

Read `AGENTS.md` first. It's binding. Do only what this brief asks.

## Goal
One command, `pnpm check`, enforces lint, types, tests with coverage floors, the layer rules (R-1..R-8, R-12), dead code and duplication. Every layer rule is proven to catch its violation.

## SRD
§10.1 (enforced layering), §14 (CI gates), NFR-QL-1 (no `any`), NFR-QL-2 (coverage floors).

## Files
- Create: `eslint.config.js`, `.dependency-cruiser.cjs`, `knip.json`, `.jscpd.json`, `tools/gates/gates.spec.ts`, `tools/gates/vitest.config.mts` (a Vitest project, added to the root `vitest.config.ts` projects), and fixtures under `tools/gates/fixtures/`.
- Modify: root `package.json` scripts; root `vitest.config.ts` (add the gates project; turn on coverage).

## Rules in `.dependency-cruiser.cjs` (exact names; tests assert them)
| Name | Forbids |
|---|---|
| `domain-no-framework` | `modules/*/domain/**` importing anything outside its own `domain/` except `@aitrader/contracts`; any npm package other than `@aitrader/contracts` |
| `application-no-infrastructure` | `modules/*/application/**` importing `modules/*/infrastructure/**` or `modules/*/api/**` |
| `api-application-only` | `modules/*/api/**` importing `modules/*/infrastructure/**` or `modules/*/domain/**` |
| `module-public-api-only` | `modules/X/**` importing `modules/Y/**` (Y ≠ X) other than `modules/Y/application/index.ts` |
| `shared-no-modules` | `shared/**` importing `modules/**` |
| `no-circular` | cycles |
| `web-feature-public-api-only` | `features/X/**` importing `features/Y/**` (Y ≠ X) other than `features/Y/index.ts` |
| `web-shared-no-features` | web `shared/**` importing `features/**` |

The paths must match both the real trees (`apps/api/src/...`, `apps/web/src/...`) and the fixture trees (`tools/gates/fixtures/<case>/...`).

## ESLint (`eslint.config.js`, flat config, ESLint 10 + typescript-eslint 8 strict-type-checked)
- `@typescript-eslint/no-explicit-any: error`
- `no-restricted-properties` on `process.env`: error everywhere except `apps/api/src/main.ts` and `**/*.config.*`
- `max-lines: ['error', { max: 250, skipBlankLines: true, skipComments: true }]` for `apps/web/src/**/*.tsx`
- `eslint-plugin-react-hooks` 7 (recommended) for `apps/web/**`
- `no-console: error` in `apps/*/src/**`, except `apps/api/src/main.ts`
- Ignore `dist`, `coverage`, `node_modules`, `tools/gates/fixtures`, `architecture/generated`, `spikes`.

## knip and jscpd
- **knip:** workspaces `apps/*` and `packages/*`; entry points `apps/api/src/main.ts`, `apps/web/src/main.tsx`, the config files and specs. Report unused files, exports and dependencies, and fail on any. The empty packages' `export {}` must not count as a finding: use knip's `ignore` only for `packages/*/src/index.ts`, with a comment that tasks 6 and 8 fill them.
- **jscpd:** `threshold: 0`, `minTokens: 60`, formats typescript/tsx, ignore specs, fixtures, dist and generated; report `console` and `markdown` into `architecture/generated/` (create the folder with a `.gitkeep`).

## Coverage (`@vitest/coverage-v8`)

- `apps/api/src/modules/*/domain/**`: 90
- `packages/*/src/**`: 90

Globs with no files pass. Exclude specs, configs, `main.ts` and `main.tsx`.

## Tests to write first (`tools/gates/gates.spec.ts`)
Each runs dependency-cruiser through its Node API (`cruise` from `dependency-cruiser`) with the repo config against one fixture, and asserts on `output.summary.violations`:
- `rejects domain importing @nestjs/common` → a violation with `rule.name === 'domain-no-framework'`
- `rejects application importing infrastructure` → `application-no-infrastructure`
- `rejects api importing infrastructure` → `api-application-only`
- `rejects importing another module's internals` → `module-public-api-only`
- `rejects shared importing modules` → `shared-no-modules`
- `rejects cycles` → `no-circular`
- `rejects a web feature importing another feature's internals` → `web-feature-public-api-only`
- `accepts a correct module tree` → zero violations for `valid`
- `accepts a correct web feature tree` → zero violations for `web-valid`

Also an ESLint test, `rejects any and process.env`: lint a string with ESLint's Node API (`new ESLint().lintText(code, { filePath: 'apps/api/src/x.ts' })`) and expect messages for the rules `@typescript-eslint/no-explicit-any` and `no-restricted-properties`.

## Steps
1. Write the fixtures and tests. Run `pnpm vitest run tools/gates` and confirm they FAIL (no config); paste the tail.
2. Add the configs and dependencies (exact latest versions: eslint 10.x, typescript-eslint 8.x, eslint-plugin-react-hooks 7.x, dependency-cruiser 18.x, knip 6.x, jscpd 5.x, @vitest/coverage-v8 matching vitest 5.1.0). Run `pnpm install`.
3. Make the tests pass. Then make `pnpm check` exit 0 on the current code, fixing real findings in the existing code rather than weakening rules.
4. Write `docs/tasks/T-003.result.md` (AGENTS.md §0).

## Done when

- `pnpm check` exits 0.
- No rule is disabled or weakened for existing code.
