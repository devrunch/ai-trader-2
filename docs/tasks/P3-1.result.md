## What changed

- `apps/api/src/modules/market-data/application/ports/bar-publisher.ts`: optional application publisher contract for forming and closed bars.
- `apps/api/src/modules/market-data/application/ports/bar-sequence-store.ts`: read port for current sequences and retained updates.
- `apps/api/src/modules/market-data/application/read-seq.ts`: reads the current sequence and replays retained updates after a sequence, returning empty when the requested point predates retention.
- `apps/api/src/modules/market-data/application/live-bars.ts`: publishes forming updates after successful throttled writes and closed bars after successful upserts; logs publisher failures without failing persistence and uses the persistence fence.
- `apps/api/src/modules/market-data/infrastructure/redis-bar-publisher.ts`: atomically increments, publishes and caps the retained list with one Lua script; validates updates and bounds Redis calls.
- `apps/api/src/modules/market-data/infrastructure/redis-bar-sequence-store.ts`: reads sequence and retained updates from Redis.
- `apps/api/src/modules/market-data/market-data.module.ts`: wires Redis publisher and sequence reader and exports `ReadSeq`.
- `apps/api/src/modules/market-data/api/market-data.controller.ts`: adds guarded `GET /api/v1/bars/seq?symbol=` with canonical instrument resolution.
- `apps/api/src/modules/market-data/api/market-data.controller.spec.ts`: tests the sequence endpoint and response contract.
- `packages/contracts/src/market-data.ts`: adds strict `BarUpdateSchema` and `BarSeqResponseSchema` contracts and inferred types.
- `apps/api/src/modules/market-data/application/live-bars.spec.ts`: covers publish-after-persist, forming throttling, leader fencing and failure isolation.
- `apps/api/src/modules/market-data/infrastructure/redis-bar-publisher.spec.ts`: covers sequence assignment, JSON updates and capped retention.
