Read `AGENTS.md` first. It's binding. Do only what this brief asks.

## Goal
The React SPA skeleton every feature builds on:
- typed routing, with symbol and interval in the URL;
- TanStack Query for server data;
- Zustand for UI state;
- the API client that speaks our error contract;
- theme tokens (light and dark);
- shadcn/Radix primitives;
- a responsive terminal layout (three resizable regions on desktop, tabs on phones).

Fast and light.

## Interfaces
- **Consumes:** `ErrorBodySchema`, `ERROR_CODES`, `ErrorCode` from `@aitrader/contracts` (T-006).
- **Produces:**
  - **`class ApiError extends Error`:** `readonly code: ErrorCode; readonly status: number; readonly requestId: string | undefined; readonly details: Record<string, unknown> | undefined`.
  - **`isRetryable(err: unknown): boolean`:** true only for `ApiError` with code `UNAVAILABLE` or `PROVIDER_DOWN`.
  - **`apiFetch<T>(path: string, opts: { schema: z.ZodType<T>; method?: 'GET'|'POST'|'PUT'|'PATCH'|'DELETE'; body?: unknown; signal?: AbortSignal }): Promise<T>`:**
    - the base URL comes from `import.meta.env.VITE_API_URL`, default `'/api'`;
    - JSON in and out; `credentials: 'include'`;
    - on 2xx, parse with `schema`; a failed parse throws `ApiError` with code `INTERNAL` and message `'Unexpected response shape'`;
    - on non-2xx, parse the body with `ErrorBodySchema`. If it parses, throw `ApiError` with its code, message and requestId. If it doesn't parse, throw `ApiError` with code from the status (404 → `NOT_FOUND`, 429 → `RATE_LIMITED`, 503 → `UNAVAILABLE`, else `INTERNAL`);
    - a network failure (`TypeError` from `fetch`) throws `ApiError` with code `UNAVAILABLE` and status 0;
    - an abort is rethrown as is (an `AbortError` `DOMException`), never wrapped.
  - **`safeStorage`:** `{ get(key): string | null; set(key, value): void; remove(key): void }`. Every call is wrapped in try/catch; when storage throws or is missing, it behaves as empty and is a no-op.
  - **`useThemeStore`** (Zustand): `{ mode: 'system' | 'light' | 'dark'; setMode(mode): void }`. It loads from `safeStorage` (`'aitrader.theme'`), writes back on change, and applies `document.documentElement.dataset.theme = mode` for light or dark, deleting the attribute for system.
  - **`createQueryClient()`:** `staleTime: 30_000`, `gcTime: 300_000`, `retry: (n, err) => n < 2 && isRetryable(err)`, `refetchOnWindowFocus: true`.
  - **Routes (code-based TanStack Router):**
    - `/` is Home: a placeholder with heading "Home" and skeleton cards;
    - `/terminal` is Terminal, with `validateSearch` via Zod: `symbol` is a string matching `/^[A-Z0-9_]+:[A-Z0-9_&.!\- ]+$/`, default `NSE:NIFTY`; `interval` is one of `1, 3, 5, 15, 30, 60, 240, 1D, 1W, 1M` (strings), default `5`. An invalid value falls back to the default, never throws to the user.
  - **`AppShell`:** a top bar with the app name, nav links (Home, Terminal) and a theme toggle cycling system → light → dark; it renders the outlet.
  - **`TerminalLayout`:** props `{ watchlist: ReactNode; chart: ReactNode; side: Record<'chat' | 'positions' | 'news' | 'alerts', ReactNode> }`.
    - **Desktop** (`min-width: 768px`): three resizable panels, watchlist (left, default 18%), chart (centre), side tabs (right, default 26%).
    - **Mobile:** one column of tabs (Chart, Watchlist, Chat, Positions, News, Alerts).
    - The terminal route passes placeholders showing the current `symbol` and `interval`.
  - **`useIsDesktop()`:** `useSyncExternalStore` over `matchMedia('(min-width: 768px)')`; falls back to desktop when `matchMedia` is missing.

## Theme (`theme.css`, Tailwind 4 with an `@theme inline` mapping)
- **Tokens on `:root`:** `--background`, `--foreground`, `--panel`, `--panel-foreground`, `--muted`, `--muted-foreground`, `--border`, `--accent`, `--accent-foreground`, `--up`, `--down`, `--warning`, `--ring`, plus shadcn's expected names mapped to these.
- **Light values** on `:root`. **Dark values** under `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { … } }` and again under `:root[data-theme="dark"]`.
- **Palette:** a calm, professional trading-terminal look:
  - dark: a near-black blue-grey background, slightly lighter panels, low-contrast borders;
  - `--up` teal-green and `--down` red, both meeting WCAG AA on panels;
  - one accent (blue).
- `body` gets an explicit background and colour. Components use tokens only (AGENTS §4).

## Tests to write first
- **`http.spec.ts`** (mock `fetch` with `vi.stubGlobal`):
  - `apiFetch parses success with schema`;
  - `apiFetch throws ApiError with server code and requestId` (a 404 body with code `NOT_FOUND`, message `x`, requestId `r1` → code `NOT_FOUND`, requestId `r1`, status 404);
  - `apiFetch maps a non-contract error body by status` (503 HTML body → `UNAVAILABLE`);
  - `apiFetch maps network failure to UNAVAILABLE` (fetch rejects `TypeError` → status 0);
  - `apiFetch rejects a success body that fails the schema` (→ `INTERNAL`);
  - `apiFetch rethrows aborts unwrapped`;
  - `isRetryable is true only for UNAVAILABLE and PROVIDER_DOWN`.
- **`theme-store.spec.ts`:**
  - `defaults to system`;
  - `persists and applies dark` (`data-theme` is `dark`, storage holds `dark`);
  - `theme store survives throwing localStorage` (stub `getItem` and `setItem` to throw; it initialises to `system`; `setMode('dark')` doesn't throw and still applies `data-theme`).
- **`terminal-layout.spec.tsx`:**
  - `shows three regions on desktop` (matchMedia stub true → testids `region-watchlist`, `region-chart`, `region-side` present);
  - `shows tabs on mobile` (stub false → a tab list with 6 tabs, the Chart tab selected).

  - `reads symbol and interval from the URL` (`/terminal?symbol=NSE:RELIANCE&interval=15` renders `NSE:RELIANCE` and `15`);
