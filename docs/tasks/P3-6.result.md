## Bugs found by the real run (all fixed here, test first)
1. **The live socket never connected in dev.** The Vite proxy lacked `ws: true`, so the page sat on "Reconnecting…". Fixed in `apps/web/vite.config.ts`.
   - **Production note:** whatever fronts the API must also pass WebSocket upgrades on `/api/socket.io`.
2. **A dead socket meant a blank chart.** The first bars came only from the socket snapshot. `LiveChart` now also loads the latest page over HTTP and merges it, so first paint never waits on the socket.
   - Test: `paints the latest page over HTTP even if the socket never delivers`.
3. **Holes after the newest stored bar were never repaired on read.** `ReadBars` filled only older history. On this machine RELIANCE showed nothing after 13:05.
   - New domain function `tailGap`, from the exchange calendar: the forming minute is excluded, with 2 minutes of slack while open.
   - New `CandleStore.latest1m`.
   - `ReadBars` fills the tail on latest and since reads, at most once a minute per instrument. A tail the vendor has nothing for is not asked again until new minutes are due.
   - Verified live: RELIANCE went from ending at 13:15 (240 minutes) to ending at 15:14 (359 minutes) after one chart load.
   - Tests: 7 `tailGap`, 3 `ReadBars`, 1 `latest1m` integration.
4. **Quote change was null.** `previousClose` stopped at the first previous session even when it had no bars (here the Muhurat window). It now skips empty sessions.
5. **The status said `ok` while the market was closed.** `MarketDataService` now reports `stale: MARKET_CLOSED` when the instrument's calendar is closed, unless a worse reason applies. The clock is injected; tests are pinned inside session hours.

## Findings that need owner-side facts (not changed here)
- **Closing Auction Session.** Since 3 Aug 2026 F&O-eligible stocks stop continuous trading at 15:15 (an auction runs 15:15–15:35), so minute bars end at 15:14. From 7 Dec 2026 the auction moves to 15:30–15:40.
  - The NSE calendar still says 09:15–15:30 for all stocks.
  - It needs per-segment sessions, from the NSE circulars and F&O eligibility per instrument.
- **Muhurat 2026.** Kite has bars on Sunday 8 Nov from 14:20 to 15:14 IST; our calendar has 18:00–19:00. Verify against the NSE circular.
- **The previous close for instruments with no stored previous session** (NIFTY, MCX, FX) is still null. It should come from daily bars, filled on demand.
- **US stocks return NO_DATA.** No US history is stored and the read-through fill returned nothing; investigate `us-delayed` history.
