# AG-5 trading desk (TradingAgents pattern, built natively)

- Desk (`agent/application/trading-desk.ts`, `desk-roles.ts`): news, technical and macro analysts (fundamentals recorded as skipped: no data source), bull/bear debate (1 round, max 2), trader, risk manager = code gate (side, reward:risk >= 1.5, size by code from 0.5% risk) plus an LLM veto with reasons; final BUY/SELL/HOLD with confidence, full trail and tokens stored in `desk_runs` (migration `0031_trading_desk`). Roles are single structured-JSON calls (AI SDK `generateText` + `Output.object`) on `DESK_MODEL` (falls back to `AGENT_MODEL`), no tool loops.
- Time machine: every input goes through `DeskData.snapshot(symbol, asOf)`; bars count only once closed, indicators are computed from bars cut at the as-of bar, news/calendar take an `asOf` (`NewsService.list`, `EconomicCalendar.list`, news store `until`), and results are filtered again so a source that over-returns cannot leak (tested with a deliberately leaky source). Limit: the LLM itself may remember later events; the prompts forbid it but cannot prove it. News history is only what the 14-day store kept.
- Desk backtest (`desk-backtest.ts`, `domain/desk-score.ts`): max 30 dates, cost estimate first (`POST /v1/desk/backtests/estimate`), runs in the background at 10:00 IST per date, scores each decision on later bars (stop wins a tie, R multiples; hit rate, average R, total R, max drawdown in R). Scoring is native code, not the compute service (a fixed entry/stop/target does not fit its condition DSL).
- Triggers: `watchNews`/`watchEvent` accept `desk`; `DeskTaskRunner` runs the desk on a match: HOLD silent; BUY/SELL placed on the paper venue through `AgentTrader` after the risk gate and the task's auto-trade limits (journaled), otherwise a `place-order` card. Desk entries cannot satisfy `requireBacktest` (no rule backtest in that run), so such a task must set it off or the entry is reported as not placed.
- Cost guard: `DESK_MAX_TOKENS` per run (stops with status `budget` and a HOLD), `DESK_DAILY_RUNS` per user (default 60; backtest dates count), tokens and calls shown per run. Web: `/desk` page (run now / as of, role cards, debate, decision and veto, past runs, backtest estimate/start/progress/results).
- Tests: role schemas, asOf leak tests, debate bounds, risk veto and code gate, budget stop, daily cap, backtest scoring on fixed data, domain scoring/gate specs, web desk specs. Gate (lint, typecheck, test, depcruise, knip, jscpd, build) passes. NOT RUN: `pnpm test:int` (no Docker here); `test/desk-store.int-spec.ts` is unverified.
- Citation and licence (Apache-2.0, commit 9fa1196) and arXiv:2412.20138 are in `docs/third-party/skill-packs.md`. The LLM roles were never run against a real model here.
- Judgment calls: roles get their data inline instead of calling tools (deterministic, leak-proof, cheaper) and use the AI SDK directly rather than a Mastra Agent; a desk watch needs a symbol (`desk.symbol` or the first watch symbol).
