## Parse rules
1. Trim surrounding whitespace.
2. Split on the **first** `:`. Both sides must be non-empty.
3. **Exchange:** uppercase it; it must match `^[A-Z0-9_]{1,20}$`.
4. **Ticker:** 1–64 characters; no control characters (`\u0000-\u001f`, `\u007f`). Keep it as written, except: when the whole input contains no uppercase letter, uppercase the ticker (`nse:reliance` → `NSE:RELIANCE`). Inner spaces are kept (`BSE:BSE SENSEX SIXTY 65:35`).

```ts
export type InstrumentChangeKind = 'listed' | 'renamed' | 'delisted' | 'expired' | 'updated';
export interface InstrumentChange { kind: InstrumentChangeKind; id: InstrumentId; successor?: InstrumentId; at: string }
export function diffMasters(prev: readonly Instrument[], next: readonly Instrument[], at: string,
  identity?: (i: Instrument) => string | undefined): InstrumentChange[];
```

## diffMasters rules
- `at` is an ISO timestamp, copied into each change.
- `identity` returns a stable non-ID key (ISIN, or a vendor token supplied by the caller); it defaults to `i.isin`.
- **Renamed:** the ID is absent from `next`, but another `next` instrument has the same identity under a new ID → one change `{kind:'renamed', id: old, successor: new}`. The new ID gets no `listed` change.
- **Expired:** absent from `next`, not renamed, and `expiry < at.slice(0,10)`.
- **Delisted:** absent from `next`, not renamed, not expired.
- **Listed:** in `next`, not in `prev`, and not the successor of a rename.
- **Updated:** in both, with any field (other than `id`) differing by deep comparison.
- **Output order:** by kind (`renamed`, `delisted`, `expired`, `listed`, `updated`), then by ID string. Deterministic.

## Tests to write first
**`instrument-id.spec.ts`:**
- `parses and formats canonical ids`: `' nse:reliance '` → `'NSE:RELIANCE'`; `'BSE:BSE SENSEX SIXTY 65:35'` → exchange `BSE`, ticker `BSE SENSEX SIXTY 65:35`; `'NSE:ARE&M'` keeps `&`; `'MCX:GOLD1!'` keeps `!`.

- `equals compares exchange and ticker`.
