# Task T-006: Error model

Read `AGENTS.md` first. It's binding. Do only what this brief asks.

## Goal
Every API error leaves as `{ code, message, details?, requestId }` with a stable code from one shared list. Nothing leaks: no stacks, no SQL, no raw messages from unknown errors.

## Interfaces
- **Produces, in `@aitrader/contracts`:**
  - `ERROR_CODES` (`as const`): `['VALIDATION_FAILED','NOT_FOUND','UNAUTHORIZED','FORBIDDEN','CONFLICT','RATE_LIMITED','SYMBOL_NOT_FOUND','MARKET_CLOSED','PROVIDER_DOWN','UNAVAILABLE','INTERNAL']`, and `type ErrorCode = typeof ERROR_CODES[number]`;
  - `ErrorBodySchema` (Zod, strict object): `{ code: z.enum(ERROR_CODES), message: z.string().min(1), details: z.record(z.string(), z.unknown()).optional(), requestId: z.string().min(1) }`, and `type ErrorBody`.

  The contracts package must work in both the API (Node, CommonJS or ESM) and the web app (Vite). Give it `"type": "module"` and an `exports` map with `types` and `default` that points at the built output. Where Vite and Vitest need the TypeScript source directly, add a `development`/`source` condition. Prove both consumers resolve it.
- **Produces, in the API:**
  - `abstract class DomainError extends Error` with `abstract readonly code: ErrorCode`, `abstract readonly httpStatus: number`, `readonly details?: Record<string, unknown>`;
  - subclasses:
    - `NotFoundError` (404, `NOT_FOUND`);
    - `ValidationError` (422, `VALIDATION_FAILED`);
    - `ConflictError` (409, `CONFLICT`);
    - `RateLimitedError` (429, `RATE_LIMITED`), constructor `(message: string, retryAfterMs: number, details?)`;
    - `UnavailableError` (503, `UNAVAILABLE`).
  - `GlobalExceptionFilter`, implementing `ExceptionFilter`:
    - `DomainError` → its status, code, message and details. Log at `warn`.
    - A Zod `ZodError` → 422 `VALIDATION_FAILED`, `details.fields` = `[{ path: 'a.b', message }]`.
    - A Nest `HttpException` → its status. Code by status: 400 or 422 `VALIDATION_FAILED`, 401 `UNAUTHORIZED`, 403 `FORBIDDEN`, 404 `NOT_FOUND`, 409 `CONFLICT`, 429 `RATE_LIMITED`, 503 `UNAVAILABLE`, otherwise `INTERNAL`. Message from the exception, except for 5xx, which use `"Internal error"`.
    - Anything else (an `Error`, a string, `undefined`, `{}`) → 500 `INTERNAL`, message `"Internal error"`, no details. Log at `error` with the stack when there is one.
    - **`requestId`:** taken from `request.id` if it's a non-empty string, else the `x-request-id` header, else `"unknown"`. Task 7 wires the real request id.
    - **`RateLimitedError`:** the response header `Retry-After` = `ceil(retryAfterMs / 1000)` seconds.
    - **Logging:** through Nest's `Logger` for now (Task 7 replaces it with pino).

## Tests to write first
**`error-body.spec.ts`:**
- `ErrorBodySchema accepts a valid body`
- `ErrorBodySchema rejects unknown codes` → `code: 'TEAPOT'` fails
- `ErrorBodySchema rejects extra keys` → `stack: '...'` fails (strict)

**`global-exception.filter.spec.ts`.** Use a tiny Nest app (`@nestjs/testing` plus supertest) with a test controller that throws on demand:
- `maps DomainError to its status and code` → `NotFoundError('Order not found', { id: '7' })` gives 404 `{ code: 'NOT_FOUND', message: 'Order not found', details: { id: '7' } }`
- `maps Zod validation failures to 422 VALIDATION_FAILED with field details` → `details.fields[0].path === 'qty'`
- `maps Nest HttpException 404 to NOT_FOUND` → a route that doesn't exist gives 404 `NOT_FOUND`
- `maps unknown Error to 500 INTERNAL without stack or message leak` → `throw new Error('SELECT * FROM secrets')` gives 500, `message === 'Internal error'`, and the body text doesn't contain `SELECT` or `at `
- `filter maps thrown non-Error values to INTERNAL` → throwing `'boom'`, `undefined` and `{}` each give 500 `INTERNAL`
- `always includes requestId` → with the header `x-request-id: abc-123`, the body has `requestId === 'abc-123'`; without it, `requestId === 'unknown'`
- `sets Retry-After for RateLimitedError(1500)` → the header is `'2'`, status 429
- `every response body satisfies ErrorBodySchema` → parse each body from the cases above
