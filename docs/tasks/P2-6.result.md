Round 1 below supersedes the original endpoint, app-ID configuration and
5,000-candle paging descriptions in this initial implementation record.

## What changed

- `apps/api/src/modules/market-data/infrastructure/deriv/deriv.messages.ts`: validates ticks, subscription IDs, candles and errors; builds subscribe, forget, ping and bounded history commands (FR-MD-1).
- `apps/api/src/modules/market-data/infrastructure/deriv/deriv-ws.client.ts`: abortable live transport with current-connection subscription IDs and 30-second pings; separate correlated history sockets prevent history blocking ticks (E5).
- `apps/api/src/modules/market-data/infrastructure/deriv/deriv-history.provider.ts`: 5,000-candle chunks, null volume, typed errors, 15-second deadlines and a three-failure/60-second breaker (FR-MD-1, E6).
- `apps/api/src/modules/market-data/infrastructure/deriv/deriv.feed.ts`: adapts Deriv to unchanged ResilientFeed for calendar-aware watchdog, reconnect, resubscription and gap repair (E1, E2, E5).
- `apps/api/src/modules/market-data/infrastructure/us/yahoo.mapping.ts`: isolates Yahoo symbol conversion, chart parsing and error mapping, including numeric HTTP error codes.
- `apps/api/src/modules/market-data/infrastructure/us/us-delayed.provider.ts`: Yahoo chart history with seven-day minute chunks, 30-day retention checks, 15-second deadlines and a three-failure/five-minute breaker (FR-MD-1, E6).
- `apps/api/src/modules/market-data/infrastructure/us/us-delayed.feed.ts`: open-session polling every minute, rotating ten-symbol batches with one-second spacing, close-time deduplication and stale/recovery states; exposes delayMs 900000 (FR-UI-8).
- `apps/api/src/modules/market-data/application/ports/live-feed.ts`: adds optional delayMs and the us-delayed feed name.
- `apps/api/src/modules/market-data/application/ports/history-instruments.ts`: allows mapping lookups for all three providers.
- `apps/api/src/modules/market-data/application/fill-history.ts`: routes FX/OANDA and US exchange IDs to their providers and preserves source provenance in storage.
- `apps/api/src/modules/market-data/infrastructure/feed/gap-backfill.ts`: shares existing minute-aligned repair/persistence behavior between Kite and Deriv.
- `apps/api/src/modules/market-data/infrastructure/kite/kite-ticker.feed.ts`: delegates its existing gap callback to the shared helper without changing behavior.

- `apps/api/src/shared/config/app-config.ts`: adds optional DERIV_APP_ID with default 1089.
- `apps/api/src/shared/config/load-config.spec.ts`: verifies the public app ID default.
- `apps/api/src/modules/market-data/application/fill-history.spec.ts`: verifies Deriv and US routing and persistence provenance.
- `apps/api/src/modules/market-data/infrastructure/deriv/deriv.messages.spec.ts`: verifies parsing and exact request shapes.

- `apps/api/src/modules/market-data/infrastructure/us/us-delayed.feed.spec.ts`: verifies session gating, polling cadence, repeated-bar suppression, stale recovery, delay metadata, batching and subscription reference counts.

## Round 1

### What changed

- `deriv-ws.client.ts`: both live and history sockets default to
  `wss://api.derivws.com/trading/v1/options/ws/public`; no app_id query is added.
  Explicit root overrides remain available for tests (FR-MD-1, E5).
- `deriv.messages.ts`: history commands contain count 1000 and an inclusive
  epoch-second end; start is never sent.
- `deriv-history.provider.ts`: pages backwards from to minus one second, then
  from the oldest returned epoch minus the resolution. Empty pages move the
  cursor backwards by 1,000 intervals, allowing traversal of closed-market gaps.
  Stops when from is covered or after 20 pages. Filters to [from,to), deduplicates
  by bar start and sorts ascending. A wholly empty window returns NO_DATA,
  including closed FX windows, as permitted by the revised brief (FR-MD-1).
  Existing timeouts and breaker behavior remain intact (E6).
- `deriv.feed.ts`, `deriv.feed.spec.ts`, `market-data.module.ts`: remove app-ID
  arguments and configuration injection from the Deriv factories.
- `app-config.ts`, `load-config.spec.ts`: remove DERIV_APP_ID and its default assertion.
- `deriv-history.provider.spec.ts`, `deriv.messages.spec.ts`: replace forward
  chunk expectations with exact backwards command/cursor assertions; add closed
  window, weekend-gap traversal and 20-page cap cases.
- `deriv-ws.client.spec.ts`: deterministic socket mock checks both live and
  history default URLs without app_id.
- `apps/api/test/deriv-feed.int-spec.ts`: fake server enforces the public path,
  rejects start, checks count 1000, returns backward-looking candle pages and
  models closed FX windows as empty candles (E1, E2, E5).
- `scripts/smoke/deriv-us.ts`: selects the last full hour before the most recent
  completed FX-calendar session close; prints each history count or provider
  reason and prints feed/catch failures as reason codes. Still manager-run only;
  not executed.
- `architecture/features/market-data/README.md` and generated artifacts: update
  the provider table and Deriv sequence for the public socket and backward pages.
