## Deviations from the brief, and why

- Repair is shared in FillHistory, which BackfillHeld invokes for both resolutions.
  This reuses the same mergeRepair/write path for read-through and nightly history,
  preserving live-only provenance and avoiding duplicated reconciliation logic.
- Added the small HistoryInstruments port and InstrumentHistory public application
  service to honor R-5 and supply canonical volume metadata without parsing vendor
  symbols outside the Kite adapter. The instruments module exports it globally
  to avoid cross-module infrastructure/module imports.
- The SDK does not accept an AbortSignal for getHistoricalData. The caller's wait
  and further chunks are canceled immediately by withTimeout; the SDK's actual
  underlying request is bounded by its own 15-second timeout.
- Existing empty-page tests now assert the requested typed failure, and existing
  page consumers narrow the new result union. Port signal additions expose
  cancellation already supported by the concrete storage adapters.
