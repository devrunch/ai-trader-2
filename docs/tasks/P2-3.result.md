## Deviations from the brief, and why

- The performance test measures the specified 60 sessions / 22,500 minutes
  first: these yield 4,500 five-minute candles, not 5,000. It then adds eight
  sessions (25,500 minutes total) and asserts an actual 5,000-candle page.
  Both timings must be at most 800 ms (NFR-PF-2).
- Added a small application session-cache helper to reuse P2-1 aggregation
  within the timing budget. The first unoptimized integration read took
  1,587.68 ms; no domain grid or dependency rules were weakened.
- Extended the existing test isolation helper because AppModule now owns a
  market-data feature with infrastructure dependencies; standalone health
  and app tests must retain their infrastructure-free fixtures.
