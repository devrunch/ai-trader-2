## Deviations from the brief, and why

- Extended `apps/api/tsconfig.json` and `knip.json` so the new integration tests
  are typechecked, linted and included in unused-code/dependency analysis.
- Updated existing boot/health unit tests to override the newly imported
  infrastructure modules; unit tests remain deterministic and offline.
- Added pool-size validation tests to the existing config suite.
- Database recovery is lazy: failed readiness probes set a full-jitter reconnect
  cooldown; the next eligible probe reconnects through pg.Pool. Queries are not
  automatically replayed, avoiding duplicate writes.
- Development migrations explicitly target the supplied Compose credentials;
  the CLI config does not read process.env, preserving R-9.
