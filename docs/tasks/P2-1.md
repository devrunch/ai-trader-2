The pure domain of the new `market-data` module:
- **Market calendars:** sessions, holidays and special sessions per exchange.
- **The session-anchored interval grid.**
- **Aggregating** 1-minute bars to any interval.

- **The live-vs-vendor repair merge.**

No I/O; time is always passed in.

## Interfaces (exact)

export interface Bar { time: number /* bar start, epoch ms UTC */; open: number; high: number; low: number; close: number; volume: number | null; repaired?: boolean }
// interval.ts

export function intervalMinutes(i: Interval): number | null;    // null for 1D/1W/1M
// calendar.ts
export interface SessionWindow { open: number; close: number }  // epoch ms UTC, half-open [open, close)
export interface MarketCalendar {
  readonly id: string; readonly timezone: string;
  sessionsOn(date: string /* YYYY-MM-DD in calendar tz */): SessionWindow[]; // [] on holidays/weekends; >1 window allowed
  isOpen(at: number): boolean;
  nextOpen(at: number): number | null;                          // null if none within 14 days
  sessionContaining(at: number): SessionWindow | null;
}
export function calendarFor(exchange: string): MarketCalendar;   // NSE, BSE, NFO→NSE, MCX, FX, OANDA, NASDAQ, NYSE, NYSEARCA, AMEX, CBOE, IEX
// grid.ts
export function bucketStart(at: number, interval: Interval, cal: MarketCalendar): number | null; // null when `at` is outside every session (intraday) or not a trading day (1D/1W/1M)
// aggregate.ts
export function aggregate(bars1m: readonly Bar[], interval: Interval, cal: MarketCalendar): Bar[]; // sorted input; volume sums, null if all null; repaired if any repaired
// bar-builder.ts
export class BarBuilder {
  constructor(cal: MarketCalendar, opts?: { lateToleranceMs?: number /* default 2000 */ });
  onTick(t: { at: number; price: number; cumVolume?: number | null; seq?: number }): { updated?: Bar; closed?: Bar[] };
  closeDue(now: number): Bar[];          // closes the forming bar once now >= its end
  forming(): Bar | null;
  restore(forming: Bar | null, lastCumVolume: number | null): void; // E16 rebuild
}
// repair.ts
export function mergeRepair(live: readonly Bar[], vendor: readonly Bar[]): { bars: Bar[]; repairedCount: number };

## Calendar data (`calendars/*.ts`; curated, with a comment citing the source)
- **NSE/BSE/NFO:** `Asia/Kolkata`; normal session 09:15–15:30; Monday to Friday.
  - Trading holidays for 2026 and 2027, as a curated list from the exchanges' published circulars; add a `// source:` comment with the circular reference.
  - The Muhurat session 2026 as a special window (use 18:00–19:00 IST on the Diwali date in the circular, marked `// confirm yearly`).
  - No pre-open: 09:00–09:15 builds **no** bars.
- **MCX:** `Asia/Kolkata`; 09:00–23:30 normally. When the US is on daylight saving time (second Sunday of March to first Sunday of November, computed from `America/New_York`), it runs to 23:55. Exchange holidays are the same list as NSE, *but* MCX keeps its evening session (17:00–23:30/23:55) on holidays flagged `eveningOnly`. Mark that clearly as a curated flag.
- **NASDAQ, NYSE, NYSEARCA, AMEX, CBOE, IEX:** `America/New_York`; 09:30–16:00. NYSE holidays computed by rule (New Year, MLK, Presidents, Good Friday, Memorial, Juneteenth, Independence, Labor, Thanksgiving, Christmas, with the observed-date rules). Half days (13:00 close) on the day before Independence Day, the day after Thanksgiving and Christmas Eve, when they're weekdays.
- **FX and OANDA:** UTC; continuous from Sunday 22:00 to Friday 22:00 UTC. Daily bars use the 17:00 New York close (the standard FX day), computed with DST.

## Grid rules
- **Intraday intervals:** buckets are anchored to each session's open (`open + k * interval`). The last bucket in a session is shortened to the close (NSE 15m: 09:15, …, 15:15–15:30).
- **FX intraday:** anchored to UTC epoch multiples (`floor(at / ms) * ms`).
- **`1D`:** the session date. **`1W`:** the ISO week starting Monday, in the calendar's time zone. **`1M`:** the calendar month.
- **Daily FX bars:** the 17:00 New York cutover.

## Builder rules
- **Boundaries (E12):** a tick at exactly a bucket boundary belongs to the new bucket.
- **Duplicates (E11):** a tick with a `seq` ≤ the last seen `seq` is ignored.
- **Out-of-order ticks (E11):** a tick for the current bucket updates it. A tick for an earlier, already-closed bucket that's within `lateToleranceMs` of that bucket's end is applied to that closed bar, which is returned again in `closed` with the updated values. Older than that, it's dropped.
- **Outside sessions:** ticks produce nothing (`{}`).
- **Volume:** from `cumVolume` differences, giving the bar's share. When `cumVolume` is null, the volume is null. On the first tick after `restore`, the baseline is `lastCumVolume`.

## Repair rules (`mergeRepair`)
- **Union by `time`.**
- **Vendor wins** on any difference in OHLC or volume; that bar is marked `repaired: true` and counted.
- **Live-only bars are kept as they are**, because the vendor may not have published them yet.
- **Output** is sorted by time.
