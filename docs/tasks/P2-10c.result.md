- Connect flow for the manager to diagram: Zerodha login redirects to the P2-10d same-site callback page, which posts `request_token` to the admin token endpoint; the API exchanges it, checks the returned account against configured `KiteCredentials.userId`, saves only a matching account's token and clears the CAPTCHA lock.
