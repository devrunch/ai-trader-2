# AG-8 events: specs, actuals, scorecard, watchers

- Knowledge and actuals: the 693 vendored ForexFactory event specs (measures, usual effect, why, beat direction; 29 "lower is better") ride on every event (`spec`). Actuals are captured near release (job `event-actuals`, polls only from -2 to +90 min): FRED for 16 curated USD series when `FRED_API_KEY` is set (off cleanly otherwise; only the observation for the event's reference period is accepted) and the RBI policy rate from the MPC resolution (real fixtures). `surprise = actual - forecast` in the event's units; `surpriseZ` over the event's own stored surprises (needs >= 8 releases). The MoSPI calendar is now discovered automatically from the site (current PDF read with `unpdf`, merged with the vendored dates); MoSPI actuals are skipped (PDF-only figures). Migration 0036; the upsert never wipes a stored actual.
- Scorecard: reaction at +5/+15/+60 min from the release MINUTE's first price (stored 1-minute bars via new `MinuteBars`), stored per event and instrument (migration 0037, job `event-reactions`); history per title with surprise vs move and per-instrument stats (beat/miss averages, how often the move followed the surprise); `asOf` hides later actuals and moves; `GET /v1/calendar/scorecard`, agent `getEventScorecard`, the Home calendar widget shows spec, actual, surprise badge, reaction line and a scorecard panel, and the desk's macro analyst now reads specs, actuals and scorecard history for events in its window. Event `moves` are now canonical instrument ids (e.g. NSE:NIFTY, FX:USDINR, MCX:CRUDEOIL1!) so they can be measured; asset-class labels stay plain.
- More sources (docs/EVENTS.md): `eia` crude inventory schedule (live; schedule only, actuals need an EIA key) and `twelve-data-earnings` (US universe; the earnings calendar needs a paid Twelve Data plan, unverified live, off without the key). Skipped: NSE corporate results (connections reset without bot workarounds, which we do not use) and BSE (no stable endpoint, no stated terms).
- Watchers: `event` trigger `minSurprise` / `minSurpriseZ` (waits for the actual, gives up 90 min after release) with the release-minute reactions in the wake-up; `briefMinutes` pre-event brief stating both branches (scorecard history and the user's positions at risk) once per event, and the release run asks which branch happened; new `move` trigger (instruments or a universe, % within N minutes, one report per instrument per hour); tools `watchEvent` (new options) and `watchMove`; REPORT/SILENT, autoTrade and desk as for other watches.
- Gate (lint, typecheck, test, depcruise, knip, jscpd, build) passes (`chat.spec` once timed out under load and passed alone). NOT RUN: `pnpm test:int` (no Docker): migrations 0036/0037 and `event-actuals` / `event-reactions` int-specs. Unverified live: FRED and Twelve Data (no keys here), RBI/MoSPI page shapes beyond the recorded fixtures; a desk-enabled event watch with `briefMinutes` would also run the desk on the brief (not guarded).
- Keys: `FRED_API_KEY` and `TWELVE_DATA_API_KEY` are in app-config, `.env.example` and the compose env list. `docs/DATA-SOURCES.md` statuses updated.
