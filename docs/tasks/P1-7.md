## Goal

## Exact behaviour
- **`useOpenOnType(open: (initial: string) => void)`:** on `keydown` of a single printable `[A-Za-z0-9]`, with no Ctrl/Meta/Alt, when focus isn't in `input`, `textarea`, `select` or a `contenteditable`, call `open(key)`. Remove the listener on unmount.
- **The dialog:**
  - a cmdk `Command`;
  - exchange filter chips: All, NSE, BSE, MCX, FX, OANDA, NASDAQ, NYSE;
  - a type select: All plus `INSTRUMENT_TYPES`;
  - each result row shows `id`, `description`, an exchange badge and a type label;
  - arrow keys move; Enter selects; Esc closes.
- **`useSymbolSearch(q, { exchange?, type? })`:** TanStack Query with key `['instruments','search',q,exchange,type]`; the query is debounced 150 ms; `placeholderData: keepPreviousData`; the request is cancelled through the query `signal`; `limit=20`.
- **Selecting a result:** navigate to `/terminal` with `search: (prev) => ({ ...prev, symbol: id })`, which keeps `interval`. Close the dialog and push `id` to the recent list.
- **Recent symbols:** `recent-symbols.ts` keeps the last 10 unique IDs, newest first, in `safeStorage` under `aitrader.recentSymbols`. With an empty query, the dialog shows recents (if any) above the API's popular defaults.
- **States:**
  - first load: a skeleton of 6 rows;
  - refetching: keep the previous rows with a subtle progress bar;
  - empty: `No matches for "<q>"`;
  - error: `Couldn't search right now`, the error `code`, and a Retry button.
- **Plain search params:** configure the router with `parseSearch` and `stringifySearch`, so `?symbol=NSE:RELIANCE&interval=15` round-trips without JSON quotes. Encoding a `:` as `%3A` is fine; quotes are not.
