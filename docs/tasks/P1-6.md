## Contracts (`@aitrader/contracts`)
```ts
export const INSTRUMENT_TYPES = ['stock','index','futures','option','forex','metal','commodity','etf','bond'] as const;
export const InstrumentSummarySchema = z.object({ id: z.string(), description: z.string(), exchange: z.string(), type: z.enum(INSTRUMENT_TYPES), currency: z.string(), status: z.enum(['active','suspended','delisted','expired']) });
export const InstrumentSchema = InstrumentSummarySchema.extend({ ticker, timezone, session, pricescale, minmov, lotSize, expiry?, strike?, optionType?, underlying?, isin?, sector?, hasIntraday, volumeType, aliases: z.array(z.string()) });
export const InstrumentSearchResponseSchema = z.object({ query: z.string(), results: z.array(InstrumentSummarySchema) });
export const ResolvedInstrumentResponseSchema = z.object({ instrument: InstrumentSchema, via: z.enum(['renamed','continuous']).optional(), resolvedFrom: z.string().optional() });
```
Every object is strict.

## Search index (MiniSearch)
- **Document fields:** `id` (the stored key), `ticker` (boost 4), `aliases` (boost 3, joined), `description` (boost 1), `isin` (exact match only, via a separate `Map<isin, id>` lookup first).
- **Query:** `prefix: true`, `fuzzy: 0.2` (only for terms of length ≥ 4), `combineWith: 'AND'`. Tokenise on spaces and the characters `-:/`; lowercase everything, but keep `&` inside tokens (`are&m`).
- **Exact ID:** if `q` parses as an `InstrumentId` that exists, it ranks first.
- **Ranking**, applied after MiniSearch scoring, deterministically:
  1. an exact ticker or alias match;
  2. status active or suspended over delisted or expired;
  3. type order: index, stock, etf, continuous (`!`), futures, commodity, forex, metal, option, bond;
  4. score;
  5. shorter ticker;
  6. `id` ascending.
- **Filters:** `exchange` (exact) and `type` (exact), applied before the limit.
- **Empty `q`:** popular defaults in this order: `NSE:NIFTY`, `NSE:BANKNIFTY`, `BSE:SENSEX`, `NSE:RELIANCE`, `OANDA:XAUUSD`, `FX:EURUSD`, `NASDAQ:AAPL`, then any that exist, filtered.
- **Atomic rebuild:** build the new MiniSearch instance fully, then swap the reference. A search during a rebuild uses the old index.
- **Port:** `search(q: string, opts: { exchange?: string; type?: InstrumentType; limit: number }): InstrumentSummary[]`.

## REST (`api/instruments.controller.ts`, mapped to application use cases only, R-3)
- **`GET /api/v1/instruments/search?q=&exchange=&type=&limit=`:**
  - query validated with Zod: `q` 0–64 characters (trimmed), `exchange` `[A-Z0-9_]{1,20}`, `type` from `INSTRUMENT_TYPES`, `limit` integer 1–50, default 20;
  - invalid → 422 `VALIDATION_FAILED`;
  - response matches `InstrumentSearchResponseSchema`.
- **`GET /api/v1/instruments/:id`:**
  - `:id` is the URL-encoded canonical ID (e.g. `NSE%3ARELIANCE`, `BSE%3ABSE%20SENSEX%20SIXTY%2065%3A35`), resolved via `ResolveInstrument`;
  - response matches `ResolvedInstrumentResponseSchema`;
  - unknown → 404 `SYMBOL_NOT_FOUND` with `details.suggestions`.
- **Global prefix:** set `app.setGlobalPrefix('api')` in `configureApp`, excluding `health` and `ready`, so routes are `/api/v1/...`. Update the existing tests if needed.
- **Rate limit:** search is cheap but public. Add a per-IP `TokenBucket` (`@aitrader/resilience`) guard on both routes (capacity 30, 10/s); over the limit → `RateLimitedError` (429 with `Retry-After`).

## Expired-ID rule (manager ruling from the P1-5 review)
Expired derivatives are purged 30 days after expiry; their `instrument_changes` rows remain.
- **`ResolveInstrument`:** when `findById` finds nothing, check the change history for an `expired` (or `delisted`) change on that ID. If one exists, throw `SymbolNotFoundError` with `details: { id, reason: 'expired' | 'delisted', at: <change at>, suggestions }`.
- **Repository:** add `findLastChange(id): Promise<InstrumentChange | null>`.
- **Test:** `a purged expired id reports reason expired with its date`.
